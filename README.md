# PBH-Accretion-2026

This repository contains Python implementations of primordial black hole (PBH) accretion models based on the accretion model developed by Ali-Haïmoud & Kamionkowski (2017). The project was developed as part of my undergraduate research at New York University under the supervision of Professor Yacine Ali-Haïmoud.

The code includes independent implementations of published accretion models, comparisons with the original numerical implementation, and exploratory calculations examining how different physical assumptions and computational choices influence the predicted thermal-feedback calculations.

## Reference

Ali-Haïmoud, Y., & Kamionkowski, M. (2017). *Cosmic microwave background limits on accreting primordial black holes*. Physical Review D, **95**, 043534.

https://journals.aps.org/prd/abstract/10.1103/PhysRevD.95.043534
